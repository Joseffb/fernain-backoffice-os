# Department Gems

The `department-prompts/` directory contains selected prompt-reference fields from seven department configurations. Use each file as a starting point for its department Gem, then review it with the department owner and add only approved source-backed guidance.

The references do not share one fixed schema. Each contains only fields available in its source, and the Legal reference has a smaller field set. These files are not a common permission policy and do not configure Workspace access, application guards, or external effects.

Keep each Gem within its department's approved source scope. Require direct source references for factual answers, distinguish known facts from missing information, and route sensitive or binding decisions to an authorized reviewer. A Gem response must not turn a request into permission to update records, change access, make payments, or send communications.
